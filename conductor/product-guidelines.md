# Product Guidelines

## Prose Style
- **Technical & Precise:** All documentation and tool output must prioritize precision and clarity. Technical terms should be used correctly, and explanations should be concise.

## UX Principles
- **Informative Feedback:** Every user action through the CLI should result in clear, informative feedback. The tool must communicate what it's doing and why.

## Visual Style
- **Clean ANSI Colors:** Use ANSI colors to improve the readability of the terminal output without creating visual clutter. Colors should be used purposefully to highlight key information (e.g., solved vs. given numbers).
- **Multiple Formats:** Support both pretty-printed, human-readable text and structured formats like JSON or CSV to cater to different use cases and integration needs.
